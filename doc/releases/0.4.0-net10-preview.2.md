# DXSharp .NET 10 preview 2 candidate

This candidate adds public native DirectX projections and depth/stencil support for external renderers.

- DXSharp.Native contains the generated Windows x64 interfaces, structures, constants, and entry points for D3D9/10/11/12, DXGI, DXC/FXC, DirectML, Direct2D, DirectWrite, WIC, DirectComposition, UIAnimation, audio, DirectInput, XInput, and GameInput represented by Win32Metadata 71.0.37-preview.
- Core adds D16, D24S8, D32, and D32S8 targets, depth/stencil clears, stencil reference, front/back stencil pipeline state, and multiple color-target binding.
- NativeInterface<T> supplies typed ownership for queries, adopted references, and borrowed references. RecordNative retains supplied DXSharp dependencies through submission completion.
- DepthStencil renders and reads back stencil masks across all four supported depth formats and exercises early owner disposal.
- ApiCoverage compares public types and member names with the pinned metadata. The build gate rejects omissions in the measured families.

Cross-compilation and metadata coverage do not establish native overload ABI correctness or GPU behavior. Windows WARP, hardware, and NativeAOT qualification must pass before publication. DirectStorage is absent from this pinned metadata and requires a separate binding source. See [API coverage](../API-Coverage.md) for the measured boundary.
