# CharacterLab — native Win32 host

The same scene, camera, model and precompiled Framework shaders as CharacterLab, hosted without Windows Forms. Build/run this project normally, or use `--warp --frames=9 --resize-test` for a bounded software-rendering check. The existing keyboard/mouse controls are unchanged. No DXC compiler DLL is required at runtime. See [the shader/host contract](../../doc/Shader-Build-and-Hosting.md).
